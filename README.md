# 국민신문고 민원답변 누락검사 스크립트

국민신문고 민원 처리결과 답변의 양식 준수 여부를 자동으로 검사하는 Python 스크립트입니다.

## 검사 항목

### 1. 답변양식 준수 검사
민원답변(처리결과)에서 아래 3가지 필수 항목의 누락 여부를 검사합니다:
- **담당부서**: 부서명 목록 엑셀에서 매칭
- **담당자**: 이름 패턴 추출 (2~4글자 한글 + 직급)
- **연락처**: 전화번호 패턴 추출

### 2. 만족도 조사 안내 여부
민원답변에 만족도 조사 참여 안내 문구가 포함되어 있는지 검사합니다.

## 사용법

### 필요 파일
1. `국민신문고 1월 처리결과 답변.xlsx` - 검사할 민원 처리결과 파일
2. `광양시 부서명(2026.2.11.).xlsx` - 부서명 목록 파일 (A열: 부서명)

### 실행
```bash
python 민원답변_누락검사.py
```

### 설정 변경
스크립트 상단의 설정 부분을 수정하면 됩니다:
```python
INPUT_FILE = r'국민신문고 1월 처리결과 답변.xlsx'  # 검사할 파일
DEPT_FILE = r'광양시 부서명(2026.2.11.).xlsx'      # 부서명 목록 파일
VERSION = 'v3'                                      # 버전
RESULT_COL = 6                                      # 처리결과 열 (F열)
```

## 출력 결과

### 출력 파일명
`{원본파일명}_누락검사_{타임스탬프}_{버전}.xlsx`

예: `국민신문고 1월 처리결과 답변_누락검사_20260211_160000_v3.xlsx`

### 시트 구성

#### 1. 전체목록 시트
| 열 | 내용 |
|---|---|
| A~F | 원본 데이터 (신청번호, 신청일자, 접수번호, 민원제목, 민원종류, 처리결과) |
| G | 누락항목 (없음 / 담당부서, 담당자, 연락처) |
| H | 부서 (추출된 부서명) |
| I | 담당자 (추출된 담당자명) |
| J | 연락처 (추출된 전화번호) |
| K | 만족도조사안내 (O/X) |

**색상 표시:**
- 노란색: 1개 누락
- 주황색: 2개 누락
- 빨간색: 3개 누락

#### 2. 월별통계 시트
- 전체 민원답변 수
- 답변양식 준수 현황 (준수/미준수 건수 및 비율)
- 만족도 조사 안내 현황 (O/X 건수 및 비율)
- 답변양식 미준수 목록 (팀별 그룹화, 건수 내림차순)

## 패턴 설명

### 담당자 이름 추출 패턴
- `OOO 주무관/사무관/계장/팀장/과장`
- `OO팀 OOO(전화번호)`
- `OO과 OOO(전화번호)`
- `담당자:OOO` 또는 `담당:OOO`
- `(전화번호, OOO)`

### 전화번호 추출 패턴
- `☎061-797-2699` (기본 형식)
- `☎061-797-2699,2868,2869` (복수 내선번호)
- `(797-2680)` (지역번호 없는 형식)

### 만족도 조사 안내 패턴
- `만족도조사를 실시`
- `만족도 조사를 실시`
- `만족도조사에 참여`
- `만족도 조사에 참여`
